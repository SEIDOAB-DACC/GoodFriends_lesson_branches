# seido-template Branch

This is the **seido-template** branch — the designated template branch for student use as described in the [README](README.md) and [LICENSE](LICENSE) files.

## What this means

- This branch is the only branch students may use as a starting point for their own derivative projects.
- Derivative projects may be used for both educational and commercial purposes, provided they include the required attribution to Seido AB.
- All other branches in this repository are for internal, experimental, or instructional purposes and are **not** permitted for reuse without written approval from Seido AB.

## Required Attribution

Any public or commercial project derived from this branch must include the following notice:

> "This project was initiated using a template provided by Seido AB as part of their course curriculum. All original template code © Seido AB. Learn more about Seido AB and our educational programs at https://seido.se"
